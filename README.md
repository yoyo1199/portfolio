
# You‑Hwa Mungai — Portfolio (GitHub Pages)

This is a simple, multi‑page portfolio you can deploy on **GitHub Pages**.

## How to use

1. **Create a repo** named `you-hwa-mungai.github.io` under your account (or rename for the account you’ll use).
2. Download this folder and push all files to the repo root.
3. Visit `https://you-hwa-mungai.github.io` after the push finishes (usually within a minute).

### Edit the site
- Replace email addresses (`contact@example.com`) with your real contact.
- Put your real photos/paintings into `assets/img/` and update captions.
- Edit text in each `index.html` to your story and services.
- Add more pages by copying any folder that has an `index.html`.

### Optional: Custom domain
In your repo, add **Settings → Pages → Custom domain** and follow the DNS instructions.

Enjoy!
