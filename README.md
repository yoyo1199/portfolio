
# You‑Hwa Mungai — Portfolio

A modern, responsive portfolio showcasing multidisciplinary creative work including photography, coding, poetry & music, painting, and local services.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Fast Loading**: Clean, minimal CSS with no external dependencies
- **Multi-page Structure**: Dedicated sections for different creative disciplines
- **Professional Contact**: Integrated contact forms and service booking
- **GitHub Pages Ready**: Easy deployment with no build process required

## Sections

- **About**: Personal introduction and overview of services
- **Photography**: Portrait and documentary photography portfolio
- **Coding**: Web development projects and technical skills
- **Poetry & Music**: Creative writing and musical compositions
- **Painting**: Acrylic and watercolor artwork
- **Hair & Dog Walking**: Local service offerings with pricing
- **Business**: Professional services and consulting

## Setup Instructions

### For GitHub Pages Deployment

1. **Create a repository** named `your-username.github.io` under your GitHub account
2. Upload all files to the repository root
3. Enable GitHub Pages in repository settings
4. Visit `https://your-username.github.io` after deployment (usually within a few minutes)

### Customization

- **Contact Information**: Update email addresses throughout all HTML files
- **Images**: Replace placeholder images in `assets/img/` with your own work
- **Content**: Edit text in each `index.html` to reflect your personal story and services
- **Colors**: Modify CSS variables in `assets/css/styles.css` for custom branding
- **Domain**: Add custom domain in GitHub Pages settings if desired

### Local Development

Simply open `index.html` in a web browser for local viewing. No build process or server required.

## Technical Details

- **HTML5**: Semantic markup with proper accessibility
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **Responsive**: Mobile-first design with breakpoints at 768px and 480px
