# Youhwa "Yoyo" Mungai - Portfolio

A modern, responsive portfolio website showcasing my creative work, coding projects, and photography.

## 🌟 Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: Dynamic galleries, image filters, and interactive demos
- **Comprehensive Showcase**: 
  - Personal journey and timeline
  - Photography gallery with categorization
  - Coding projects and technical skills
  - Contact form and social links

## 📁 Project Structure

```
portfolio/
├── index.html              # Landing page (redirects to home.html)
├── home.html               # Main portfolio page
├── aboutme.html            # About me section with personal timeline
├── coding_experience.html  # Technical projects and skills
├── photography.html        # Photography gallery
├── Thank_You.html          # Contact confirmation page
├── css/
│   └── style.css          # Modern CSS with animations and responsive design
└── README.md              # This file
```

## 🎨 Design Features

- **Color Scheme**: Purple gradient theme (#667eea to #764ba2)
- **Typography**: Modern, clean fonts with good readability
- **Animations**: Smooth scroll effects, hover animations, and fade-in transitions
- **Navigation**: Fixed navbar with smooth scrolling
- **Gallery**: Filterable photography gallery with overlay effects

## 🚀 Technologies Used

- **HTML5**: Semantic markup and modern structure
- **CSS3**: Flexbox, Grid, animations, and responsive design
- **JavaScript**: Interactive features, DOM manipulation, and smooth scrolling
- **Font Awesome**: Icons for enhanced visual appeal

## 📱 Responsive Design

The portfolio is fully responsive and optimized for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (320px - 767px)
